# Fusion FX Funded — Project Prototype

> ⚠️ **Prototype Only — Not a Live Service** ⚠️
>
> This repository contains a design prototype for a fictional trading firm brand called "Fusion FX Funded."
> **No real trading accounts, payments, evaluations, or payouts are offered or available.**

## Contents

- `index.html` — A polished, responsive single-page landing page prototype for Fusion FX Funded.
- `README.md` — This documentation file.

## How to Preview

1. Clone or download this repository.
2. Open `index.html` in any modern web browser (double-click the file).
3. The landing page will render locally with full CSS styling and responsive design.

Alternatively, preview the live-rendered HTML on GitHub by visiting:
`https://github.com/Die6Another9Day/fusion-fx-funded/blob/main/index.html`

All account sizes, pricing figures, profit targets, drawdown limits, and rules shown on the landing page are **illustrative placeholders** created for design demonstration purposes only. They should not be interpreted as real product offerings.

## Design

- **Theme**: Premium fintech aesthetic
- **Base colors**: Black / charcoal (`#0a0a0f`, `#16161e`)
- **Accents**: Restrained red (`#e63946`) and bright green (`#00e676`)
- **Typography**: Inter (Google Fonts)
- **Responsive**: Mobile-first with breakpoints at 768px and 480px

## Sections in index.html

1. **Navigation** — Fixed top bar with logo and links
2. **Hero** — Headline, description, disclaimer banner, CTAs
3. **Account Cards** — 5 account tiers ($5K / $25K / $50K / $100K / $200K) with illustrative pricing and rules
4. **Why Fusion** — Feature cards with placeholder descriptions
5. **Sample Rules** — Table of illustrative trading rules
6. **FAQ** — Accordion-style FAQ (all prototype disclaimers)
7. **Contact CTA** — Placeholder call-to-action
8. **Footer** — Branding, links, and prototype notice
